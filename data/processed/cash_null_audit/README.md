# Cash-null audit: shared gate helper outputs

Generated by `scripts/reconcile_cash_null_audit.py` (checked by `tests/test_gate_metrics.py`).

- `reconciliation.csv` / `reconciliation.md`: Sharpe in excess of BIL and legacy Sharpe_rf0 recomputed by
  `usa_etf_features.gate_metrics` on the committed OOS returns of every archived gate and the live books, compared
  with Quant's cash-null audit memo (2026-09-26). One printed memo figure does not reproduce and is explained there
  (VCFC Book-2 VT legacy rf=0 printed 0.88; audit script and helper both give 0.8747).
- `rf_fallback_share.csv`: share of each gate window that uses the FRED TB3MS fallback (months before BIL's first
  full month, 2007-06).
- `trial_counts.json`: VCFC 12-trial and #6 72-trial grid counts vs the memo.
- `site_sharpe.json`: every Sharpe the Pages site displays (excess of BIL headline + legacy rf = 0).
- `shortlist_strategy_returns.csv` (input): monthly OOS returns for `static_option_a`, `vol_target_option_a`,
  `score_rotate_xsd`, `m3_p2_core_rotate` over 2021-02..2026-09, from
  `usa-etf-features run-strategies --walkforward` with only those four registry entries enabled
  (prices `/workspace/investments/growth_alpha_adj_close.csv`). Sharpe_rf0 for static / XSD / M3 matches the CIO
  `run_latest/strategy_comparison.csv` exactly; `vol_target_option_a` in this file is the current registry entry
  (VT × gate-first overlay, Sharpe_rf0 1.2798 = the #6 run).

rf rule: BIL priced monthly total return (committed monthly panel) from BIL's first full month (2007-06); before
that FRED TB3MS / 1200 (`data/raw/fred_tb3ms.csv`). Sharpe_exBIL = mean(r − rf)·12 / (std(r − rf)·√12).
Sharpe_rf0 (legacy, rf = 0) = CAGR / vol, unchanged.
