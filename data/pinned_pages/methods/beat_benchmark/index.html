1. Downside-volatility backbone (top pick among trial candidates)

It changes one line of Book 2's backbone: risk is measured on down days only. Wang & Yan (2021) report that this adds return timing, the axis Book 2 lacks. Barroso & Detzel (2021) find that the managed market portfolio is the case that survives costs. Turnover is unchanged. Its main virtue is that the new series is 0.998-correlated with the backbone, so a paired test can detect a Sharpe gap of about 0.07 in 60 forward months. It is the only idea we can actually settle against its null. The honest catch is that the likely true gain is small: +0.027 over 2018-12 to 2026-09 and about zero over 2021-02 to 2026-09. It also does not beat the static core on CAGR at 10 bp (−2.37 pp and −0.26 pp on those windows). It therefore does not qualify for a holdout spend, and none is proposed.

2. Blend frontier between the static core and Book 2 (decision aid, no trial)

This is the most direct way to see what "beating the core" would cost. It is the line of fixed mixes from all-core to all-Book 2 over the 68-month hub window, with a preference point set by drawdown tolerance. For example, a −15% tolerance gives w = 0.70. No trial is charged because nothing is selected from returns. Its own numbers say every mix gives up CAGR against the core at 10 bp, so if a w were ever pre-registered and run forward, it would be unlikely to clear the Book rule.

3. HAR volatility forecast

This is a faster, forecast-based risk estimate (HAR, with Christensen et al. 2023 as the modern benchmark study). In-sample it looked best over 2018-12 to 2026-09 (+0.083 Sharpe vs the backbone). But the sign flips on 2021-02 to 2026-09, MaxDD is worse and turnover rises to 77%/yr. It trades away the drawdown control Book 2 was admitted for, so it ranks last.

Considered and not shortlisted

  • Conditional (extreme-state-only) volatility targeting (Bongaerts et al. 2020). Our backbone already scales only down, so it is half-conditional already, and the in-sample version was slightly worse (−0.020).
  • Trend or drawdown overlays. Family-2 B3 (core-vs-cash timing) was 0.95-correlated with Book 2 and inconclusive, so another tail overlay would be redundant.
  • Volatility-managing EW or the DeMiguel base. Capped EW is only a secondary null for Book 2 (its 68-month null rerun is pending in #57), and the DeMiguel tilt fails the turnover rule. Neither targets Jared's actual default.
  • Beating the core on CAGR outright. In this family that needs leverage (exposure above 1 in calm markets), which is outside the long-only rules. I don't propose it.

Data caveats

  • Live figures use the hub's Books window, 2021-02 to 2026-09 (68 complete months, corrected prices), and match the hub subject pages to full precision.
  • The in-sample illustration uses the stand-in core (IVV/QQQ/IJR), rebalanced daily, on 2016-11 to 2026-09 prices only, scored 2018-12 to 2026-09. σ* therefore starts in 2016-11, while the live backbone uses longer history. The replica correlates 0.998 with the live backbone. The stand-in core carries no rebalancing cost in the CAGR-edge test.
  • The illustration window overlaps the backbone's live out-of-sample window, so any real test must be forward.
  • There is no intraday data: realized variance is proxied by daily squared returns.
  • Simulations are bivariate normal, so they understate fat tails and crash clustering.

Glossary

DSR (Deflated Sharpe Ratio)
The chance a Sharpe ratio is real after allowing for how many strategies were tried. It's reported here, not used as a gate. Earlier pre-registered trials, such as Schur, used DSR ≥ 0.95 as one of their criteria, and any future pre-registration will set its own.
NW t (Newey–West t-statistic)
How many standard errors a return gap is from zero, with errors widened for month-to-month correlation; about 2 or more is notable.
CVaR5
The average return in the worst 5% of periods: a measure of how bad the bad tail is.
ex-BIL
Measured above the return of BIL (a 1–3 month Treasury-bill ETF), our stand-in for cash.
bp vs pp
bp = basis point = 0.01% (costs per trade); pp = percentage point (a gap between two percentages, e.g. 15.0% vs 14.5% is 0.5 pp).
Book rule
As registered: one-way turnover at most 100%/yr AND a CAGR edge over the static core that stays positive at 10 bp costs.
core
Book 1: the static 70/20/10 VOO/QQQM/IJR mix. Not the same as the backbone, which is the vol-targeted version of the core.
stand-in core
An approximation of the core built from older funds with longer price history (IVV/QQQ/IJR at 70/20/10, rebalanced daily). Used only for in-sample illustrations; its figures are not gate results or hub numbers.
w
In Idea 2, the share of the money in Book 2; the rest is in the core (w = 0 is all core, w = 1 is all Book 2).
