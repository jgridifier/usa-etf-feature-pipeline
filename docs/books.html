Book 1 · Static core

Buy-and-hold reference

What it is: Fixed weights VOO 70% / QQQM 20% / IJR 10%. No timing, no vol scale. Strategy id static_option_a.

Why it’s on the shortlist: Clean null for “did timing or risk management add anything?” Every overlay is judged against this path (and against Book 2 when the claim is risk-managed).

What it is not: Not a Justina method. Not a multifactor optimizer showcase.

OOS snapshot (panel; rf=0 Sharpe): ~14.7% ann. return · ~15.9% vol · MaxDD ~−25.6% · Sharpe ~0.92 · ~68 months (2021-02 → 2026-09). Turnover ≈ 0.

Book 2 · Vol-target

Default research path

What it is: Same Option A core, scaled by estimated volatility (scale-down only in v1); cash residual in BIL when risk is high. Strategy id vol_target_option_a.

Why it’s on the shortlist: On this panel it improves the risk path vs Book 1 (higher Sharpe_rf0, milder MaxDD) without a strong return-alpha claim vs static (NW t vs Book 1 ≈ 0). That is a path/risk book, not a “beat the market” story.

What it is not: Not the archived conditional factor-corr overlay (#13), which failed vs this unconditional Book 2 on Sharpe.

OOS snapshot (panel; rf=0 Sharpe): ~14.7% ann. return · ~13.9% vol · MaxDD ~−20.1% · Sharpe ~1.06 · same window. Modest turnover from scaling.

Not on the shortlist: Spectral risk parity (null: Ledoit–Wolf MinVar), Regime-aware dual-regime (null: Unconditional ERC), Vol-cond factor corr #13 (null: Unconditional Book-2 VT) — all FAIL — archive. Full table: Methods → Archive / Justina round-1 scoreboard.
