1. Downside-volatility backbone (top pick)

It changes one line of Book 2's backbone: risk is measured on down days only. The 2021 evidence (Wang & Yan) says this adds return timing, which is exactly the axis Book 2 lacks, and Barroso & Detzel (2021) find the managed market portfolio is the case that survives costs. Turnover is unchanged. Its main virtue is that the new series is 0.998-correlated with the backbone, so a paired test can detect a Sharpe gap of about 0.07 in 60 months, or 0.05 if the holdout were spent. It is the only idea we can actually settle. The honest catch is that the likely true gain is small: in-sample it is +0.027 over 2018-12 to 2026-08 and about zero on 2021-02 onward. It is also the only idea where I would propose spending the 2008–16 holdout, and only if a pass would actually switch Book 2's backbone.

2. Fixed 50/50 Book 2 + static core

This is the most direct answer to "beat the core." Holding half in each is the same as running Book 2's scaling at half strength. On the hub window it gives Sharpe 0.89 vs 0.78 and MaxDD −18.0% vs −25.6%, for −0.48 pp of CAGR (in-sample, every α shown on the page). The split is fixed rather than estimated, following the fixed-weight result of Wang & Yan and the estimation-risk logic of Kan, Wang & Zhou. It adds no new information: it inherits Book 2's edge and its uncertainty, and it still trails the core's CAGR in-sample. Read it as a way to present the risk-return choice to Jared, not as a discovery.

3. HAR volatility forecast

A faster, forecast-based risk estimate (HAR, with Christensen et al. 2023 as the modern benchmark study). In-sample it looked best over the long window (+0.084 Sharpe vs the backbone), but the sign flips on 2021-02 onward, MaxDD is worse, and turnover rises to 78%/yr. It also trades away the drawdown control Book 2 was admitted for, so it ranks last.

Considered and not shortlisted

  • Conditional (extreme-state-only) volatility targeting (Bongaerts et al. 2020). Our backbone already scales only down, so it is half-conditional already. The in-sample version was slightly worse (−0.020).
  • Trend or drawdown overlays. Family-2 B3 (core-vs-cash timing) was 0.95-correlated with Book 2 and inconclusive, so another tail overlay would be redundant.
  • Volatility-managing EW or DeMiguel's base. Book 2 already beats capped EW (NW t ≈ 2.07 on corrected prices, secondary null), and the DeMiguel tilt fails the turnover rule. Neither targets Jared's actual default.
  • Beating the core on CAGR outright. In this family that needs leverage (exposure above 1 in calm markets), which is outside the long-only rules. I don't propose it.

Data caveats

  • Live figures are recomputed on 67 complete months (2021-02 to 2026-08). The hub's 68-month figures include 2026-09.
  • The in-sample illustration uses the stand-in core (IVV/QQQ/IJR), rebalanced daily, from 2016-11 prices only. σ* therefore starts in 2016-11, while the live backbone uses longer history. Replica correlation with the live backbone is 0.998.
  • The illustration window overlaps the backbone's live out-of-sample window, so any real test must be forward (or a pre-registered holdout spend).
  • There is no intraday data: realized variance is proxied by daily squared returns.
  • Simulations are bivariate normal. They understate fat tails and crash clustering.
