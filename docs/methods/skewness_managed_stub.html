Core method sketch

Book-2 vol-target backbone (already live — Moreira & Muir 2017):

σ̂_t  = √252 · stdev( last L daily returns of r^A )   # data ≤ t only
f_t  = clip( σ* / σ̂_t , f_min, f_max )             # f_max = 1 (scale-down only)
w_t  = f_t · w^A + (1 − f_t) · e_cash               # cash = BIL

Skewness / left-tail overlay (this method — Gong–Lynch–Ogden mapping):

At t, compute skew / left-tail diagnostics using data ≤ t only:
  rs_t  = realized skewness (Amaya-style: √N · Σr³ / RV^(3/2))
        OR expected skewness (BMV-lite: expanding OLS on lagged rs_t)
  ℓ_t   = left-tail score (choice of):
          cvar_5              — rolling CVaR at 5% level on monthly portfolio returns
          adverse_rs          — max(0, −rs_t)
          pct_lt_neg_k_sigma  — % months with r < −k·σ_monthly

Gate g_t ∈ [g_min, 1]:
  bind (g → g_min)  when ℓ_t > expanding median of historical ℓ
  open (g → 1)      when ℓ_t ≤ expanding median (calm / favorable tail)

Effective equity scale:
  f̃_t = f_t · g_t
  w̃_t = f̃_t · w^A + (1 − f̃_t) · e_cash   # residual → BIL
