Method overview

Lead citation: Alexander, Nolan, and William Scherer. 2023. "Forecasting Tangency Portfolios and Investing in the Minimum Euclidean Distance Portfolio to Maximize Out-of-Sample Sharpe Ratios." Engineering Proceedings 39(1):34. doi:10.3390/engproc2023039034 · arXiv:2604.03948 · code (original)

The algorithm decomposes the Markowitz efficient frontier into three interpretable scalars (r_MVP, σ_MVP, u), forecasts them via an online VARX(1), maps the forecast to a forecasted tangency point (r̂_TP, σ̂_TP), then invests in the portfolio on the current frontier that minimizes Euclidean distance to that point. The geometric robustness step avoids plugging noisy μ̂, Σ̂ directly into classical tangency each period.

Core math

EF coefficients (Merton 1972 / Alexander–Scherer reparameterization):

A = 1'Σ⁻¹1 , B = μ'Σ⁻¹1 , C = μ'Σ⁻¹μ r_MVP = B/A , σ_MVP = 1/√A , u = (AC − B²)/A σ²(r) = σ_MVP² + (r − r_MVP)²/u ← frontier shape

Forecasted tangency (paper Eq. 6, rf = 0 for Sharpe_rf0 parity):

r̂_TP = (r̂_MVP² + û·σ̂_MVP²) / r̂_MVP [rf = 0] σ̂_TP = σ(r̂_TP) using forecasted frontier shape Forecast (r̂_MVP, σ̂_MVP, û) via online VARX(1) on EF-coef history ≤ t.

MED solve on current frontier:

r* = argmin_r √[ (r̂_TP − r)² + (σ̂_TP − σ_current(r))² ] w*_t = argmin_w w'Σ̂_t w s.t. w'μ̂_t = r* , 1'w ≤ 1, w ≥ 0 Residual (1 − Σwᵢ) → BIL (Appendix 3 approved cash)

Walk-forward rules (no same-month leakage)

  • At month-end t: all of μ̂_t, Σ̂_t, EF coefs, VARX forecast, MED solve, and w*_t use data ≤ t only.
  • Weights hold through month t+1; returns evaluated at t+1.
  • Leakage unit test: mutating returns after t leaves EF coefs, forecast, MED r*, and weights unchanged.
  • Universe: N ≥ 100 liquid names and/or category sleeves. Thin-history flags (thin_lt5y) applied.
  • Costs: 5 bps one-way on monthly turnover.
  • v1: long-only, leverage_cap = 1.0. No shorting; no 1.5× leverage until an explicit registered trial.

Acceptance criteria (Quant gate)

  1. OOS walk-forward equity curve + metrics vs nulls (a)–(c) exist, are reproducible from CLI, and cover N ≥ 100 name-level and/or category sleeves.
  2. Primary config shows higher Sharpe_rf0 with NW t meaningfully positive vs EW, LW MinVar, and ERC after 5 bps — or a CoS-agreed MaxDD/left-tail win with only modest Sharpe give-up.
  3. DSR + trial_count reported on every OOS Sharpe claim; leakage unit tests green.
  4. Diagnostics: time series of (r_MVP, σ_MVP, u), forecast errors, Euclidean distance, turnover, % cash.
  5. Does not silently win by shorting, 1.5× leverage, or same-month peeking.

Failure is informative: If MED forecast-tangency fails vs EW / LW MinVar / ERC after DSR, archive with a one-line null result (parity with Justina round-1 / #13). No book cut.

Distinguished from archived work

  • Not Spectral RP (eigenrisk), Regime-Aware dual (k=2 HMM), or vol-cond-factor-corr (#13 / shortlist #5 Book-2 upgrade) — all archived FAIL in scoreboard.
  • This is a cross-sectional allocation path: forecast where the tangency point will be, then pick a robust nearby portfolio on today's frontier. Scales to N ≥ 100 ETFs and/or category sleeves.
