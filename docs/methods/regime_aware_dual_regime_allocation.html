Regime-Aware Allocation with Dual-Regime Signals

Teaching note · Justina Quant shortlist pick #2 · Category sleeves + ≥100 ETF panel · Experimental research only

Research only — not investment advice. This note designs a walk-forward test of regime-conditioned selection and weighting on an experimental USA ETF panel. It does not recommend any allocation for real capital.

1. Why this paper

Static ERC / MVO and Spectral Risk Parity still assume one “average” return distribution. Jared’s research ask explicitly wants category sub-analysis and many options — which only makes sense if the ranking of categories (and which names belong in the opportunity set) changes with the market state.

Luo & Mulvey (2026), Journal of Financial Data Science, study regime-aware allocation with dual-regime signals and regime-dependent asset selection: detect regimes, then let both the signal and the eligible asset set depend on the regime.

Fit to the mandate: category sleeves as the natural “assets” inside regimes; name-level panel (≥100) as a stress test; unconditional ERC / MVO as nulls. Complements Spectral RP (risk budgeting) with a selection/timing layer.

2. What the original work found

Luo & Mulvey (2026), JFDS — dual-regime signals + regime-dependent selection

  • Setup: Dual-regime signal architecture; asset eligibility and/or weights change with the inferred regime (Journal of Financial Data Science, Summer 2026, 8(3), 104–134).
  • Claim (as published in JFDS listing): Regime-conditioned selection improves allocation versus one-regime / unconditional designs in their reported experiments.
  • Limitation for us: We must re-implement the architecture on ETF category sleeves with strict walk-forward labeling (no peeking at month-t returns when labeling regime for month-t weights). Paper sample and features may differ from a Defined-Outcome-heavy ETF panel.

Adjacent papers we will also use

  • Shu, Mulvey et al.–style line / Nystrup et al. tradition: regime models for allocation are older; we need an implementable 2020s recipe.
  • Yang & Mulvey-adjacent open literature: Shu, Yu, and Mulvey-class work; practically we lean on Dynamic Asset Allocation with Asset-Specific Regime Forecasts (arXiv:2406.09578) — jump-model labels + supervised regime forecast + Markowitz — as a transparent blueprint when JFDS full text is gated.
  • Ielpo, Muhammetgulyyeva & Royer (2026), “Building a Regime-Resilient ERC Portfolio,” Journal of Portfolio Management — regime-specific ERC blended by regime frequencies (regime parity). Excellent null / cousin for risk-based regime work (LOIM line).

3. Core math / intuition

Two layers:

  1. Regime inference — latent state s_t ∈ {1,…,K} (we start with K=2: calm vs stress) from features available at t: trailing panel vol, average pairwise corr, equity–bond / growth–defensive relative vol, etc. HMM, statistical jump models, or simple thresholds are all allowed; pick one primary and freeze it before OOS.
  2. Regime-dependent policy — given ŝ_t,
    • select eligible category set A(ŝ_t) (e.g., stress: Treasuries / quality / gold sleeves; calm: broad equity / growth / thematic sleeves), then
    • allocate with a within-regime rule (EW, ERC, or light shrinkage MVO on A(ŝ_t)).
w_{t+1} = Π( ŝ_t ; data_{≤t} ) ŝ_t = g( features_{≤t} ) # no month-t+1 information Π may zero-out assets outside A(ŝ_t)
Plain language: First guess the weather. Then only put the umbrella sleeve (or the picnic sleeve) in the shopping cart, and risk-budget inside that cart. Dual-regime signals means the weather forecast can use more than one indicator family — still causally timed.

4. What we will do on USA ETF / category-panel data

ItemChoice
Primary assetsCategory sleeves built from usa_universe_categorized.csv (EW within category among names with enough history).
Secondary stressName-level ≥100 liquid ETFs (exclude or flag thin_lt5y) to see if regime selection still helps when N is large.
Regime featuresTrailing 3–12m panel vol; mean corr; stress spread (e.g. defensive vs cyclical sleeve returns) — all lagged one month.
KStart K=2; optional K=3 only as a registered extra trial (counts against DSR).
Within-regime allocatorPrimary: ERC on eligible sleeves. Alt: EW. Optional light MVO with Ledoit–Wolf — each is a separate trial.
LeakageRegime label and weights for month t+1 use information ≤ t only. No fitting HMM on full sample then “playing” OOS labels.
Nulls(1) Unconditional ERC on all sleeves; (2) Unconditional EW; (3) Single-regime always-calm policy; (4) Cousin: regime-parity ERC blend (Ielpo et al. 2026) if Eng capacity allows.

5. How we will know it worked

  • Primary: OOS Sharpe, vol, max DD, and turnover vs unconditional ERC/EW on the same sleeves.
  • Regime diagnostics: time in each state; transition matrix stability; performance conditional on ex-post stress months (does the policy actually de-risk when realized stress hits?).
  • Mandatory: Deflated Sharpe / Bailey–López de Prado (2014) with trial count = all K choices × feature sets × allocators registered before looking at OOS.
  • Pass bar: Better risk-adjusted path or materially better left-tail vs unconditional ERC with DSR surviving multiplicity; if not, publish the miss — still useful for the book.
