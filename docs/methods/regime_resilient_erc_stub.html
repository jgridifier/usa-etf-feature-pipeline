Method summary

Justina CIO shortlist #3. Walk-forward regime-resilient ERC construction following Ielpo, Muhammetgulyyeva & Royer (2026). Two construction paths (registered separately, swept via grid):

Path A — Stress / corr-breakdown overlay

Diagnostics (≤ t): Σ̂_stress (high-vol/left-tail window), avg pairwise |corr|, sync score

Σ̂_resilient,t = (1 − λ) Σ̂_uncond,t + λ Σ̂_stress,t   (registered λ)
w*_t = ERC(Σ̂_resilient,t)   ← still ERC; only Σ changed

Path B — LOIM regime-parity construction

Historical regime pools m (≤ t; NBER-lag or rolling-vol-split):
  Σ̂_m,t ← cov estimator on regime-m sample (≤ t)
  w*_m,t ← ERC(Σ̂_m,t)
  π̂_m,t ← historical freq or Markov steady-state ≤ t

w*_t = Σ_m π̂_m,t · w*_m,t   ← π-blend of local ERCs (NOT current-regime selector)
Leakage guarantee: at month-end t, all construction inputs (stress diagnostics, regime-pool labels, Σ̂_m, π̂_m, ERC solutions) are invariant to returns after t. External NBER labels used with documented publication lag — only announced recession periods are used as pool inputs.
