Trials: 12 trials in the third-book search versus about 117 trials across all registries. The DSR penalises the number of tries that could have produced the winner. Only the 12 allocator trials competed for the third-book slot, so they set the pre-registered hurdle; the ~117 count adds unrelated searches (overlays, timing grids, VOID runs) and is the conservative sensitivity.
