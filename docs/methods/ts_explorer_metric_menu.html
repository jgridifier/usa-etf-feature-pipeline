Time Series Explorer — Quant metric menu (v1)

What a quant should see on one raw-series page for the Growth-25 panel first, with a path to the ~339-ticker universe panel. Research only — not investment advice.

Page intent. One ticker (or a small multi-select) → dense, honest analytics on the price path we actually have. No portfolio “book” framing. Prefer transparent close-to-close formulas, visible sample windows, and thin-history flags over black-box scores.

1. Why this menu

Exploratory time-series work on ETFs is mostly about stylized facts and relative co-movement, not a new alpha claim. Cont (2001) catalogues the facts every quant checks first (heavy tails, vol clustering, weak return autocorrelation, slow decay in absolute returns). Campbell, Lo & MacKinlay (1997) give the standard β / correlation language for co-movement with a market proxy. This page should make those checks one click away on our experimental panel.

2. What the literature says (short)

  • Cont (2001), Quantitative Finance — asset returns: near-zero linear autocorrelation, heavy tails, volatility clustering (persistent |r| / r² dependence). Explorer must show ACF of r and of |r| (or r²), plus a simple vol path.
  • Campbell, Lo & MacKinlay (1997), The Econometrics of Financial Markets, Ch. 4–5 — market-model β, correlation, and rolling estimation discipline. Use VOO as the default market proxy on this USA panel.
  • Tsay (2010), Analysis of Financial Time Series, Ch. 1–3 — log returns, rolling moments, QQ plots vs Normal as the default diagnostic stack.
  • RiskMetrics (J.P. Morgan / Reuters, 1996 technical document) — EWMA variance (λ ≈ 0.94 daily) as a transparent alternative to equal-weight rolling vol. Nice-to-have in v1.1.

3. Core math / intuition (close-to-close only)

Inputs are adjusted closes \(P_t\). Primary return:

r_t = \ln(P_t / P_{t-1})

Annualized trailing realized vol over window \(W\) (trading days):

\sigmâ_t(W) = \sqrt{252} \cdot \mathrm{std}(r_{t-W+1:t})

Peak-to-trough drawdown on a wealth index \(W_t = \exp(\sum_{s\le t} r_s)\):

DD_t = W_t / \max_{s\le t} W_s - 1

Rolling market β vs proxy \(m\) (default VOO):

\betâ_t(W) = \widehat{\mathrm{Cov}}(r, r^m)_W / \widehat{\mathrm{Var}}(r^m)_W

Rolling Sharpe (rf = 0 for v1 simplicity; optional excess vs BIL later):

SR̂_t(W) = \sqrt{252} \cdot \bar{r}_W / \mathrm{std}(r)_W

Leakage / honesty rules: every rolling chart titles the exact window; summary stats print start/end and n_obs; tickers with short history get a visible thin-history badge (from coverage CSV). No forward-filled returns across gaps — drop or break the series.

4. What we will do on the USA ETF / growth-panel data

v1 universe: columns of growth_alpha_adj_close.csv (Growth-25 equities + on-panel cash names if present). Default landing ticker: VOO. Peer default for pairwise plots: QQQM (or QQQ if QQQM window is short).

v1.1 path: same UI against usa_universe_adj_close.csv (~339 tickers) with search/typeahead + category filter from usa_universe_categorized.csv.

Out of scope (v1)

  • Portfolio optimizers, book weights, or “recommended allocation” language.
  • OHLC range estimators (we only publish adj close).
  • Machine-learning forecasts or regime classifiers as productized signals.
  • Any employer/firm branding (forbidden-token gate stays green).

5. How we’ll know it worked

  • Picker lists every Growth-25 ticker; switching ticker updates all blocks < 300ms on a laptop for Growth-25 client-side.
  • VOO vs QQQM: β≈1 for VOO vs VOO (sanity), corr(QQQM, QQQ) very high on overlap, thin badges appear for short names (e.g. QQQM/GTEK-class history).
  • ACF(|r|) stays elevated vs ACF(r) ≈ 0 — Cont stylized-fact smoke test.
  • Corr heat uses pairwise overlapping dates only (no silent fill).
  • Mobile: charts resize; tables scroll; firm-token CI green.
  • Research disclaimer visible; no book framing in nav copy.
