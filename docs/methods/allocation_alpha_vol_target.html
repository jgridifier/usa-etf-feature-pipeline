Allocation Alpha: Volatility-Managed Option A

Teaching note · 2026-09-16 (ET) · USA experimental ETF research · Companion to allocation_alpha_method_memo.md

Research only — not investment advice. This document explains a proposed walk-forward test of time-series risk scaling versus static Option A (VOO 70% / QQQM 20% / IJR 10%). It does not recommend buying or selling any security. Confirm tickers against the experimental USA ETF research panel before any trade.

1. Why this paper / blog

Today’s workstream already tested:

  • Static Option A and Growth+alpha mixes (G1/G2/G3)
  • XSD rotation (relative momentum / ScoreSimple gate on a thematic sleeve)
  • Walk-forward constrained MVO (composite score, James–Stein μ̂, Ledoit–Wolf covariance, P1/P2/P3)

Those change which ETFs get weight, or gate a satellite ON/OFF. They do not isolate pure allocation / timing skill: varying how much equity risk you take while keeping the same core mix.

Allocation alpha (our definition): risk-adjusted or drawdown improvement that comes from weights and timing versus a static policy portfolio (Option A), with selection held fixed. Classic language: Brinson–Hood–Beebower “timing” versus “policy,” measured as active return / IR versus the buy-and-hold core (Grinold & Kahn).

We propose one primary method: volatility-manage Option A — scale the whole equity sleeve down when recent portfolio volatility is high, park the rest in on-list T-bill ETFs (BIL). That is complementary to WF MVO and XSD rotation, transparent, and paper-backed.

2. What the original work found

Moreira & Muir (2017), Journal of Finance

  • Setup: Take standard factors / market portfolios; each period scale exposure by the inverse of recent realized variance (a “volatility-managed” version).
  • Claim: Taking less risk when volatility is high raises Sharpe ratios and produces large alphas versus unmanaged versions.
  • Economic intuition: Volatility moves around a lot; expected returns do not move enough to offset it. So cutting risk in high-vol states improves the return-per-unit-risk tradeoff.
  • Important nuance: The strategy often takes less risk in recessions — contrary to “risk premium rises in bad times” stories. That is a feature of the evidence, and a caution for storytelling.
  • Limitations: Academic factors / long histories; assumes you can increase exposure in calm markets (leverage or reducing a cash buffer). Transaction costs and implementation constraints matter for ETFs.

Harvey et al. (2018), Journal of Portfolio Management (robustness family)

  • Setup: Target a roughly constant volatility by scaling notional up/down across many assets and simple multi-asset portfolios (e.g. 60/40).
  • Claim: Sharpe gains from vol targeting concentrate in risk assets (equities, credit). Across assets, left-tail outcomes tend to be milder because nasty returns often coincide with high vol (when exposure is already cut).
  • Limitations: Results vary by asset class; equity vol targeting can partly overlap with time-series momentum via the leverage effect (vol rises after selloffs).

Attribution language we borrow

  • Brinson, Hood & Beebower (1986): Separate policy (strategic weights), timing (over/under vs policy), and selection.
  • Grinold & Kahn (2000): Active return versus a benchmark; information ratio; skill × breadth. Here breadth is monthly timing decisions, not stock picking.

3. Core math / intuition

Policy (static Option A):

w_VOO = 0.70, w_QQQM = 0.20, w_IJR = 0.10 r^A_day = 0.70·r_VOO + 0.20·r_QQQM + 0.10·r_IJR

Estimate recent vol of that same portfolio at month-end t (using only data through t):

σ̂_t = √252 · stdev( last L daily returns of r^A ) Primary L = 63 trading days

Scale factor (two equivalent research forms):

Moreira–Muir style: f_t = c / (σ̂_t)² choose c so average f ≈ 1 (documented calibration) Target-vol style: f_t = σ* / σ̂_t σ* = expanding historical AnnVol of Option A, or a grid {12%, 15%, 18%}

Clip for implementability (recommended primary):

f_t ← clip(f_t, 0.25, 1.00) # scale-DOWN only into cash; no borrowed leverage in v1

Weights:

Equity piece: f_t · (0.70, 0.20, 0.10) in VOO / QQQM / IJR Cash piece: (1 − f_t) in BIL (fallbacks: SGOV, GBIL, SHV — all on-list)

Intuition in one sentence: Same three stocks-in-ETF-clothing; when the ride gets violently bumpy, hold less of the bundle and more T-bills; when calm, hold the full Option A.

What we are not doing: re-optimizing cross-sectional weights with a composite score, rotating XSD with relative momentum, or fitting a black-box ML timer. Those are already covered elsewhere.

4. What we will do on USA ETF / growth-panel data

Assumptions

  • Universe gate: only tickers in usa_universe_categorized.csv; Appendix 3 denied; XSD remains the only on-list semis ETF if thematics appear in extensions.
  • Primary portfolio: Option A + BIL. Optional robustness: same scaler on static G1.
  • Monthly rebalance; decision at month-end t uses prices/returns ≤ t; performance measured on month t+1 only (no same-month leakage).
  • Transaction cost: ~5 bps one-way on turnover (parity with WF MVO memo).
  • Sharpe with rf = 0 for comparison with existing memos.
  • WF stays on the existing 25 growth-panel building blocks for any named extension; primary needs Option A + cash prices.

Inputs

  • Adjusted closes / monthly returns: growth_alpha_adj_close.csv, growth_panel_monthly_returns.csv (extend with BIL if missing).
  • Coverage / thin flags: growth_panel_history_coverage.csv — QQQM ~5.9y binds live Option A paths.
  • Benchmarks: static Option A (B0); secondary static G1; optional placebo “always 80% A + 20% BIL.”

Walk-forward / leakage rules

  • Vol estimator at t must not peek into t+1.
  • Calibration of c or expanding σ* uses history ending at t or t−1 only (document choice).
  • Register every trial (L, σ* or c-rule, f_max, apply-to) for multiple-testing honesty / DSR — same spirit as wf_strategy_registry.csv.

Nulls

  • H0: Vol-scaled Option A does not improve Sharpe_rf0 vs static Option A after costs (NW t on monthly excess ≈ 0; bootstrap Sharpe CIs overlap heavily).
  • Secondary H0: MaxDD is not meaningfully better once costs and trial multiplicity are acknowledged.

5. How we will know it worked

Success (research bar — not a trade signal):

  1. OOS walk-forward equity curve and metrics table vs Option A exist and are reproducible from a CLI in usa-etf-feature-pipeline.
  2. Primary config (L=63, scale-down-only, BIL) shows either (a) higher Sharpe_rf0 with NW t meaningfully positive, or (b) clearly better MaxDD / left-tail with only modest Sharpe give-up — Jared chooses which bar binds.
  3. Leakage unit tests pass; costs applied; registry lists all robustness grid points.
  4. Brinson-style note: active return attributed to months with f<1 vs f=1 (timing contribution visible).
  5. Does not silently beat the null by reintroducing score-based name picking.

Failure is also informative: If vol targeting fails OOS (plausible in a short post-2020 window with V-shaped rallies), we document that allocation timing via vol did not add skill vs buy-and-hold Option A — and keep static core as default.
